# Lalit Patil — Animated Portfolio

Stunning, smooth-animated single-page portfolio for **Lalit Patil — UI / Front-End Developer (Senior Engineering Lead)**.

- Pure **HTML + CSS + JS** — no build step, just open `index.html`.
- Sections: Home, About, Experience (all 5 roles), Skills (full resume stack), Education (all 4), Certifications (all 7), Awards (all 5), Contact.
- Effects: preloader, particle canvas, typed roles, cursor glow, 3D-tilt portrait, scroll progress, reveal-on-scroll, animated counters & skill bars, marquee, sticky glass nav, contact-via-email form.

## Run locally

Double-click `index.html`, or serve it:

```bash
npx serve .
# or
python -m http.server 8080
```

## Deploy

Any static host works (GitHub Pages / Netlify / Vercel) — upload the folder as-is.
